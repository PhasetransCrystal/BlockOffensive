玩家手册

这条路线面向进入服务器、选队、购买装备、执行目标或旁观的玩家。你不需要 Java 或地图文件知识。

连续阅读路线​

  1. 加入第一场比赛：打开地图列表、加入房间、选队并准备。
  2. 爆破模式：购买、C4、回合胜负、暂停与加时。
  3. 死斗模式：自由死斗、团队死斗、积分与出生保护。
  4. 按键、HUD 与旁观：默认按键、比分、Ping、击杀镜头和 MVP 音乐。
  5. 常见问题：按现象排查进不去、商店打不开、C4 无法交互和界面异常。

加入一场比赛​

  1. 在客户端打开 FPSMatch 地图选择界面，浏览房间的模式、地图和人数。
  2. 进入等待中的房间，选择可用队伍并点击 准备。
  3. 等待倒计时结束；比分板会显示队伍、回合和准备状态。
  4. 若房间没有出现，管理员应检查地图是否加载以及 cs/csdm 是否注册。

cs 爆破回合​

CT 负责阻止爆破或拆除 C4，T 负责在 A/B 目标区安装 C4 并守住引爆。击杀全队、完成目标或时间耗尽都会结算回合。每回合之间通常包含购买、冻结、战斗和结算阶段；具体时长由地图设置和服务器配置决定。

C4 的交互需要站在有效目标区域内。安装后，提示会显示目标状态；CT 可以使用拆弹工具缩短拆除时间。死亡后不要离开服务器，旁观流程会保留队伍信息并允许切换队友或观看击杀镜头。

csdm 死斗​

死斗模式把重点放在持续交战和击杀排名。服务器可以启用自由死斗或团队死斗、重生保护、积分、领先差距提示和回合结束统计。死斗的出生和复活策略与爆破模式分开配置，不要把 cs 的 C4 规则套用到 csdm 地图。

购买与经济​

购买阶段打开队伍商店；商品、价格、虚拟弹药、护甲和互斥分组由地图制作者配置。余额来自前几回合的胜负、击杀和模式规则。买不起完整套装时，优先和队友沟通是否保存经济；商店不可用通常意味着还没进入购买阶段、没有站在购买区或当前地图没有初始化商店。

HUD、旁观与反馈​

  • 顶部比分板显示队伍分数、回合和剩余时间。
  • 击杀反馈、死亡消息、爆头提示和队伍颜色帮助你判断战况。
  • 旁观者可以切换队友、查看击杀镜头并使用服务器提供的镜头控制。
  • TAB、队伍聊天、无线电和 Ping 标记由客户端按键绑定控制；整合包可能覆盖默认按键。

报告问题​

请提供服务器版本、FPSMatch 与 BlockOffensive 版本、模式、地图 ID、队伍、回合阶段和完整提示文字。截图或日志中的第一条报错比“进不去”更有帮助。
