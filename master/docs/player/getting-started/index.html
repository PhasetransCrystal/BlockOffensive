加入第一场比赛

BlockOffensive 的比赛由 FPSMatch 地图房间承载。房间不是 Minecraft 世界的副本；它是某张已配置地图当前的队伍、玩家、准备状态和比赛状态。

打开地图列表​

在客户端执行：

/fpsm mapselect

地图卡片会显示模式、地图名、人数和状态。cs 是回合制爆破，csdm 是死斗。若卡片图标或详情背景缺失，通常只影响展示，不代表房间不可用。

加入、选队与准备​

  1. 选择地图并打开详情页。
  2. 在等待状态加入房间。
  3. 选择 CT、T 或由系统分配可用队伍。队伍人数受地图设置限制。
  4. 点击准备。所有普通队伍玩家准备后，地图可以进入准备倒计时。

cs 默认要求 CT 和 T 都至少有一名在线玩家才满足自动开始条件。csdm 只要存在在线玩家即可满足自身的自动开始条件。服务器可以关闭准备开始或修改倒计时，因此以房间实际提示为准。

比赛中加入​

地图基础设置 allowJoinInProgress 决定比赛开始后是否还能加入。即使允许中途加入，模式仍会决定玩家何时出生：爆破模式通常需要等待合适的回合边界，死斗可以在进行中安排重生。

不要通过反复重连尝试绕过队伍或阶段限制。重连会触发服务器恢复玩家身份和快照，但不会改变地图规则。

地图列表为空​

这通常表示服务端没有成功加载地图，或没有注册 cs / csdm 游戏类型。玩家无法在客户端自行创建房间。把服务器版本、地图 ID 和界面状态交给管理员，管理员应继续检查 /fpsm help、地图数据和服务器日志。
