BlockOffensive 1.3.0 更新日志
基线：1.2.5.1（2025-10-16）
范围：截至 2026-09-16 的当前工作区快照

说明
- 本文只记录从 1.2.5.1 到当前工作区仍然存在的、玩家、服主或玩法扩展者可感知的变化。
- 1.3.0 当前为源码工作区快照；请在发布前以最终构建产物和实际依赖版本为准。

新增与重做：对局玩法
- CS 爆破模式改用完整的回合生命周期：准备、冻结/购买、进行、结算、换边、重置和比赛结束流程均由统一的回合状态驱动。
- 新增 CSDM 死斗模式，支持自由混战与团队语义、击杀排名、与第一名的差距提示，以及复活保护时间。
- CS 加入可配置的加时规则与经济处理；关闭加时时会正确结束比赛，避免反复重置。
- 加入投票流程和投票 HUD，可在比赛内发起并查看投票状态。
- C4 目标流程得到扩展：安包、拆包、拆包进度、炸弹引信、爆炸/拆除胜负判定及目标贡献会同步到客户端。
- 掉落的 C4 仅对 T 方显示带距离信息的轮廓，便于寻找目标物。
- 死亡信息支持爆头、投掷物、爆炸、自杀等特殊图标和规则；修正无来源伤害、自杀及 TaCZ 击杀场景遗漏击杀提示的问题。
- 友军伤害关闭时，C4 爆炸不会再误伤队友；C4 击杀和伤害不会再被错误计入常规击杀统计；CS 中击杀队友会施加击杀数惩罚。
- MVP 结算改为三类贡献规则，支持残局（clutch）原因，并改进赢家横幅与播报时机。

新增：玩家体验与 HUD
- 新增死亡回放与旁观镜头：死亡后会进入带灰度/世界淡出效果的击杀回放；无法取得回放时可回退到队友观战。
- 旁观 HUD 现在显示可观战玩家列表、炸弹引信、武器状态及切换提示；支持快捷切换旁观目标。
- 重做 CS 记分板、TAB 和比赛 HUD，分别呈现比分、队伍/玩家状态、死亡信息、MVP、投票及炸弹状态；死斗使用独立的排名和 TAB 展示。
- 新增战术标记（Ping）：客户端可在世界和屏幕上看到标记，并接收位置同步。
- 新增队伍聊天和无线电快捷操作；无线电使用环形菜单。
- 新增本地 MVP 音乐管理：玩家可选择目录、导入/转换本地音乐，并通过按键控制播放；服务器会管理上传和分块同步。
- 商店界面改为 Modern UI 风格，提供物品图示、玩家预览、购买过程反馈及附近比赛掉落物的拾取结果。
- 增加比赛开场演出：可按阵营播放镜头、角色动作、武器展示、音效与覆盖层；提供同步与完成确认，避免客户端卡在演出状态。

服主与地图作者
- CS/CSDM 已接入 FPSMatch 的地图房间、队伍选择、准备、开始倒计时和管理流程；可在地图浏览页搜索、筛选和查看地图详情。
- 地图支持显示名、缩略图和详情背景；资源路径由客户端资源包或模组提供，服务器不会把任意本地图片路径下发给客户端。
- 队伍与商店状态会在回合开始、换边、准备阶段和玩家变动后同步，避免不同玩家看到错误库存、队伍或购买状态。
- 退出比赛时会清理比赛重生点并传送到结束位置，减少场外玩家误回到对局中的情况。
- 地图的旧版数据可自动修复到当前格式；地图、回合、旁观和计分统计均增加了持久化/同步保护。
- 对局中继续限制地图和出生点编辑，防止正在运行的比赛被修改。

修复与兼容性
- 修复准备阶段无法打开商店、购买阶段结束后商店仍可用、聊天框打开时商店键仍触发、ESC 或背包被商店状态包错误关闭等问题。
- 修复空队伍 TAB、MVP 结算、换边商店、回合结束、离场、旁观者切换顺序和死斗流程中的多项边界问题。
- 修复敌我发光判定、死亡 HUD、爆头图标、瞄准击杀、换弹以及 C4 相关反馈在部分 TacZ 场景下不正确的问题。
- 加强 Physics Mod 布娃娃兼容：处理死亡时序、注入失败重试和代理布娃娃重复生成/清除，降低死亡后显示异常概率。
- TaCZ 不再作为 BlockOffensive 的固定玩法实现前提；枪械和投掷物改经 FPSMatch 兼容层识别，整合包可按实际玩法选择兼容模组。

开发者与 API
- 对外 Java 包名已由 com.phasetranscrystal.blockoffensive 迁移为 com.ptcrys.blockoffensive。这是二进制不兼容迁移：附属模组、脚本桥接和开发工具需要更新导入路径并重新编译。
- CS 玩法新增 Forge 事件入口：CSGameMapEvent（含队伍切换和玩家安放 C4）、CSGameRoundEndEvent、CSGamePlayerGetMvpEvent，以及 CSHUDRenderEvent.RenderMvpHud 的 Pre/Post/TriggeredAnimation。监听方可取得当前地图、队伍、玩家、C4 实体、回合胜方/原因或 MVP 原因。
- CS 地图实现拆分为 CSMap、CSGameMap 和 CSDeathMatchMap，并以 FPSMatch 1.3.0 地图生命周期驱动。继承旧 CSGameMap、依赖旧回合时序或直接改写比赛状态的扩展必须按新状态和事件时机适配。
- 网络包改由 BOPacketRegistration 集中注册；C4、商店掉落物、旁观/击杀回放、MVP 音乐、Ping 和投票均有独立客户端/服务端同步包。扩展模组应使用公开事件、地图 API 或自己的通道，不应复用这些实现细节包。
- 半场演出支持 /fpsm blockoffensive halftime 命令树，可重载配置、选择阵营演出区域、设置朝向/时长/开关、预览、清理和调试换边。地图脚本或管理工具可据此配置演出，但需要 OP 2 级权限。
- 枪械、投掷物、Physics Mod、Hit Indication 与 Modern UI 的集成均经兼容层探测。第三方玩法应使用 FPSMatch 的武器提供者/事件扩展点，不应假设 TaCZ 或某个可选兼容模组始终已加载。

部署与扩展注意事项
- 当前源码工作区面向 Minecraft 1.20.1 / Forge 47.4.10，依赖 FPSMatch 1.3.0+；客户端界面依赖 Modern UI 1.20.1-3.12.0.1。专用服务器不需要为纯客户端界面单独安装 Modern UI。
