# 爆破区与区域

`cs` 地图通过 `DemolitionModeCapability` 保存爆破区。T 只能在有效区域安装 C4，CT 在已安装实体附近执行拆除；`csdm` 不使用爆破区。

## 配置原则

- A/B 区完全位于地图边界内，并覆盖可站立的安装空间。
- 给 T 留出安装后守包路线，给 CT 留出可争夺的回防路线。
- 不要把区域只放在装饰方块或半空。
- 修改前结束当前比赛，否则能力编辑通常会被拒绝。

区域显示、添加和清理由 FPSMatch 能力命令提供；使用 `/fpsm help` 查询当前精确路径。保存后以 T 安装、CT 拆除、引爆和回合结算验证。
