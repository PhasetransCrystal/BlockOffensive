# 房间管理与验收

房间承载地图当前的队伍、玩家、准备状态和比赛状态，不是世界副本。地图作者应使用真实玩家流程验收，而不只执行调试开始。

1. 从 `/fpsm mapselect` 打开地图详情。
2. 让两名玩家分别加入 T/CT；`csdm` 同时验证自由和团队语义。
3. 检查准备、倒计时和中途加入设置。
4. 完成购买、击杀、C4 安装/拆除、死亡旁观和重连。
5. 结束后检查玩家、掉落物、比分和房间状态是否清理。

失败时记录地图 ID、模式、设置快照、当前阶段和服务器第一条相关异常。
