# 地图编辑工具

适用读者：偏好图形界面和世界内取点的地图作者。工具来自 FPSMatch，BlockOffensive 只提供 `cs`/`csdm` 类型和相应能力。

| 工具 | 用途 |
| --- | --- |
| 地图创建工具 | 选择两个对角点，创建地图或更新边界 |
| 复活点工具 | 选择模式、地图和队伍后添加出生点 |
| 对局配置工具 | 切换地图并修改设置 |
| 商店配置工具 | 打开指定队伍的商店编辑器 |

地图正在比赛时，边界和出生点编辑通常被锁定。工具行为和按键可能由 FPSMatch 版本调整，以界面提示和 `/fpsm help` 为准。
