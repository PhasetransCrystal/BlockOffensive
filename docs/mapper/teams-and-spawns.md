# 队伍与出生点

出生点是服务端保存的位置和朝向，必须位于地图边界内、地面稳定且不会让玩家卡入方块。

## 配置步骤

1. 在地图详情页选择 `cs` 或 `csdm` 地图。
2. 为 T、CT 或死斗队伍分别添加出生点；命令形式以当前 `/fpsm help` 补全为准。
3. 每个队伍至少放置能覆盖最大队伍人数的出生点，并避免所有点朝向同一路线。
4. 使用起始装备能力配置刀、护甲或其他物品。
5. 保存后让测试玩家加入、开始、死亡并重生，验证维度、朝向和碰撞。

`csdm` 的队伍容量由 `CSDMTeamSemantics.TEAM_CAPACITY` 控制；不要把死斗容量假设成 `cs` 的队伍限制。比赛中编辑出生点会被锁定。
