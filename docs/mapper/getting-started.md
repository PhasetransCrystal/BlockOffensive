# BlockOffensive 地图作者工作流

适用读者：制作地图或维护服务器的玩家。前置条件是服务器已安装 FPSMatch 与 BlockOffensive，并拥有 OP 2。本文使用 `training` 作为示例。

## 推荐顺序

建筑 → 边界 → 队伍与出生点 → 爆破区（仅 `cs`）→ 设置 → 装备 → 商店 → 房间展示 → 双人测试。

BlockOffensive 不复制建筑；它在现有世界中保存一个三维边界，并把边界绑定到 `cs` 或 `csdm` 游戏类型。地图由维度、ID、区域、队伍、能力和设置组成。

| 内容 | cs | csdm |
| --- | --- | --- |
| 队伍 | T / CT | 自由或团队死斗语义 |
| 爆破区 | 需要爆破能力 | 不使用 |
| 出生点 | T/CT 队伍 | 死斗队伍 |
| 商店 | 回合经济 | 死斗规则初始化 |

地图 ID 使用 1–48 位小写字母、数字、`_` 或 `-`；展示名称通过 `displayName` 设置。边界必须覆盖所有路线、出生区和目标区，并且处于创建地图时所在维度。
