# 按键、HUD 与旁观

所有按键都可以在 Minecraft 控制设置中重新绑定。下表是当前源码默认值。

| 功能 | 默认键 | 生效条件 |
| --- | --- | --- |
| 打开商店 | `B` | 已进入比赛且服务端允许购买 |
| 拆除 C4 | `E` | 靠近可拆除的已安装 C4 |
| 队伍聊天 | `U` | 没有其他界面占用输入 |
| Ping 轮盘 | `Z` | 比赛中，当前没有其他 Screen |
| 投票同意 / 反对 | `Y` / `N` | 当前存在活动投票 |
| 旁观上一个 / 下一个队友 | `A` / `D` | 处于旁观模式且允许切换 |
| MVP 音乐设置 | `F9` | 客户端存在玩家且没有其他界面 |

## 比赛 HUD

爆破 HUD 汇总队伍比分、存活人数、当前阶段、时间和 C4 状态；死斗 HUD 汇总排名、积分、领先差和出生保护。客户端只显示服务端同步的快照，不应把 HUD 视为修改比赛状态的入口。

击杀消息、击杀图标、观战 C4 倒计时和观战者名单可以在客户端配置中开关。若界面完全缺失，先确认 Modern UI 版本和客户端模组是否一致。

## Ping 与队伍交流

Ping 只向战术协作提供短时位置标记。公共配置默认存活 6 秒，最大渲染距离 256 格。重新 Ping 会替换该玩家之前的标记。队伍聊天使用独立输入界面，不会把消息发送给对手。

## 死亡与旁观

`allowSpecAttach` 默认开启。玩家死亡后，服务端可以发送击杀者、武器与双方视点，客户端播放击杀镜头，再附着到可用队友。`A` / `D` 只有在旁观策略允许时生效。新回合开始会清理旧击杀镜头和灰度状态。

## MVP 音乐

按 `F9` 打开本地 MVP 音乐设置。界面接受 MP3、OGG 或 WAV，并限制在 22 秒以内；保存后客户端会上传分块。该玩家获得 MVP 时，服务端可以向在场玩家分发并播放专属音乐。服务器管理员也可以用 `/fpsm mvp` 为玩家绑定资源声音。
