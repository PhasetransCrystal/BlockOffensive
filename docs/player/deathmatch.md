# 死斗模式

`csdm` 是持续交战模式。它复用 FPSMatch 的地图、出生点、队伍和商店能力，但不使用爆破回合的 C4 胜负流程。

## 自由死斗与团队死斗

地图设置中的死斗模式字段决定队伍语义。团队死斗中，同队玩家被视为队友；自由死斗中，CT/T 只是容量和出生组织方式，玩家之间不建立战斗队友关系。旁观者始终不参与队友判断。

两个运行队伍的容量均为 16。玩家加入时，服务端从可用死斗队伍中分配；比赛已经开始时可以立即进入重生流程。

## 时间与出生保护

默认比赛时长是 `12000` tick，约 10 分钟。默认出生保护为 6 秒；HUD 会显示剩余时间，移动或开火会提前取消保护。出生保护只用于避免刚重生即被击杀，不是永久无敌。

## 武器积分

死斗分数按规范化后的武器 ID 匹配。当前源码示例：

| 武器组 | 击杀分数 |
| --- | ---: |
| Zeus、P2000、Glock、USP | 18 |
| P250、双枪、Tec-9、CZ75 | 16 |
| R8、Deagle | 14 |
| UMP、Nova、Bizon、短喷、MAC-10、MP5/7/9、MAG-7 | 13 |
| XM1014、P90、SSG08、Galil、FAMAS、Negev | 11 |
| M249、AWP、G3SG1、SCAR-20 | 8 |
| 未命中特定规则的武器 | 10 |

匹配会忽略武器路径中的下划线和连字符。整合包使用自定义枪械 ID 时，可能落入默认 10 分。

## HUD 与结算

CSDM HUD 显示当前排名、分数和与第一名的差距。团队模式还会使用团队语义处理伤害和统计。比赛时间结束后进入胜利展示和清理流程，不会沿用爆破模式的回合经济。
