# 玩家常见问题

## 地图列表没有房间

客户端只能显示服务端已加载的地图。确认客户端与服务端的 BlockOffensive、FPSMatch 和 Forge 版本匹配；仍为空时请管理员检查地图数据和服务器日志。

## 商店打不开

按顺序确认：已经加入地图、比赛已开始或处于准备购买阶段、购买时间未结束、玩家位于队伍商店区、当前队伍的商店已初始化。提示“购买时间已结束”时反复按 `B` 不会重新开放商店。

## C4 无法安装或拆除

安装需要 T 身份、活动中的 `cs` 地图和有效爆破区。拆除需要靠近已安装 C4 并按住绑定的拆除键。若地图提示没有爆破区，应由地图作者配置 `DemolitionModeCapability` 区域。

## HUD、击杀镜头或房间界面异常

先检查客户端是否安装 Modern UI `3.12.0.1+`，再确认资源包与可选枪械模组版本。只在专用服务端正常、某个客户端异常时，优先收集该客户端 `latest.log`。

## 如何提交有效报告

附上 Minecraft、Forge、FPSMatch、BlockOffensive 和 Modern UI 版本，模式与地图 ID，当前队伍和阶段，完整提示文本，以及日志中的第一条相关异常。若是按键问题，再说明是否改过绑定、当时是否打开其他界面。
