# 常见问题与故障排查

适用读者：所有用户。先记录版本、模式、地图 ID 和完整错误文本，再按故障阶段排查。

| 症状 | 首要检查 | 可能原因 |
| --- | --- | --- |
| 地图列表为空 | `/fpsm help`、服务端日志 | 地图未加载或模式未注册 |
| 商店打不开 | 阶段、购买区、队伍商店 | 未进入购买阶段或商店未初始化 |
| C4 无法安装/拆除 | T 身份、爆破区、已安装实体 | 地图能力或距离条件不满足 |
| HUD 缺失 | Modern UI、客户端配置 | 客户端依赖或 HUD 开关 |
| 重连后状态错误 | 服务端第一条网络异常 | 快照未发送或版本不匹配 |
| 只装可选模组时崩溃 | 移除可选集成复现 | 端侧类加载或兼容 API 变化 |

提交问题时附上 `latest.log` 中第一条相关异常、Minecraft/Forge/FPSMatch/BlockOffensive/Modern UI 版本、模式和地图 ID、队伍与回合阶段，以及能否用最小地图复现。
