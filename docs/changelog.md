# 更新与兼容说明

当前文档对应源码工作区的动态版本 `1.2026.09-SNAPSHOT`（构建版本由日期生成）。它不是已发布的稳定版本号。历史变更详见仓库根目录 `changelog.txt`；发布包的最终依赖以对应发行页面为准。

## 升级检查清单

1. 备份世界、地图数据、配置和日志。
2. 对照新版本 `gradle.properties` 与 `mods.toml` 检查必需依赖。
3. 在副本服执行 `/fpsm help` 并打开 `cs`/`csdm` 测试地图。
4. 验证商店、C4、回合、旁观、网络重连和可选兼容模组。
5. 记录任何地图设置或数据迁移提示，再升级生产服。
