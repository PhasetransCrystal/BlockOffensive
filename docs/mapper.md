# 地图制作者手册

地图制作者不需要编写 Java。你需要把已经注册的 `cs` 或 `csdm` 连接到一段 Minecraft 世界：定义边界、出生点、目标区、装备、商店和房间展示。

## 推荐制作顺序

1. 先完成世界建筑，确保路线、掩体和目标空间可玩。
2. 使用地图创建工具建立唯一的地图 ID 和边界。ID 只能使用 1–48 位小写字母、数字、`_` 或 `-`。
3. 为 T、CT 或死斗队伍添加安全出生点，确认头部和脚部空间无碰撞。
4. 在 `cs` 地图上配置 A/B 爆破区，检查区域完全位于地图边界内。
5. 设置展示名称、自动开始、中途加入和房间图标。
6. 配置起始装备与队伍商店，最后在真实玩家房间中测试一轮。

## 管理入口

客户端地图选择：

```text
/fpsm mapselect
```

地图创建、区域、出生点、设置、商店和比赛管理入口位于地图详情页；命令行统一在 `/fpsm map` 下。地图进行比赛时，边界、出生点和爆破区编辑会被拒绝，请先结束比赛。

## 爆破区与出生点检查

爆破区必须落在地图区域内，并且应给 T 留出安装后转移和守包的路线，给 CT 留出至少一条可争夺的回防路线。出生点放在平整地面上，避免直接看见目标区或让一队拥有不可反制的首杀角度。

## 商店与展示资源

商店按队伍保存。先初始化商店类型和初始资金，再编辑枪械、护甲、弹药、价格和购买区。图标、详情背景和语言键放进资源包后，再在地图设置中填写资源位置；资源缺失时页面会显示兜底色块。

## 测试清单

- 两队都能在 15 秒内离开出生区并接触主路线。
- C4 只能在设计好的 A/B 区安装，拆除工具可正常工作。
- 回合结束、重置、重连和旁观不会把玩家留在错误队伍。
- 购买区、资金、退货和互斥商品在客户端与服务端一致。
- 地图详情页的名称、图标、背景和模式 ID 与实际房间一致。
